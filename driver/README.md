# mmldrv — mmlc 用 SPC700 サウンドドライバ

`mmlc` の動作確認と、最小構成のドライバの実例を兼ねた 8ch ドライバです。
ソース(`mmldrv.asm`)、ビルド済みバイナリ(`mmldrv.bin`, 493 byte)、
ドライバ定義(`mmldrv.drv`)の 3 点で完結します。

```
driver/
  mmldrv.asm   ドライバのソース (asar, arch spc700)
  mmldrv.bin   ビルド済みバイナリ ($0200 に配置)
  mmldrv.drv   mmlc 用のドライバ定義
  example/     demo.mml / テスト用サンプル生成 (mksample.py)
```

## 使い方

```
cd driver/example
python3 mksample.py                 # sine.brr / dir.bin を生成 (テスト用)
../../mmlc demo.mml                 # demo.spc が出来る
```

MML 側の先頭は次のようにします。

```
#driver "../mmldrv.drv"
#sample "dir.bin"  0x1F00           ; サンプルディレクトリ
#sample "sine.brr" 0x4000           ; BRR 本体
```

ドライバを改造した場合のみ再アセンブルが必要です (`asar --no-title-check mmldrv.asm mmldrv.bin`)。

## メモリマップ

| アドレス | 内容 |
|---|---|
| `$0000-$00FF` | ドライバのワーク (ゼロページ) |
| `$0200-$03FF` | ドライバ本体 |
| `$1F00-$1FFF` | サンプルディレクトリ (`DIR=$1F`、1 エントリ 4 byte: 開始/ループ) |
| `$2000-$3FFF` | 曲データ (先頭 16 byte = 各 ch のトラックポインタ) |
| `$4000-` | BRR サンプル |

## 対応機能

| MML | 内容 |
|---|---|
| `c d e ...` `o` `<` `>` | ノート。o0〜o5(`o5b` まで)。**o4c がサンプルの原音** (ピッチ値 `$1000`) |
| `r` `^` `l` | 休符 / タイ / 既定音長 (1 tick 単位。`tpq`=48) |
| `t` | テンポ(BPM)。**40〜255**。タイマー分周値の整数化により高テンポほど誤差が出る |
| `@n` | 音色 = ディレクトリのエントリ番号 (SRCN) |
| `v` | 音量 0〜127 |
| `p` | パン 0〜127 (0=左, 64=中央, 127=右) |
| `q` | ゲート。**ノート末尾 n tick を離鍵**する (0 = レガート)。`q6` で約 62ms @120BPM |
| `[ ]n` `L` | ループ展開 / 無限ループ |

`v` `p` `@` はノート開始時に反映されます。ベロシティ(`u`)は未対応です。

## 制限

- ADSR は全ボイス共通で `mmldrv.drv` の `dsp =` 行 (AR=15 DR=7 SL=7 SR=0) に固定。
  MML の `#dsp 0x05 0x..` で ch ごとに上書きできます (ボイス n のレジスタは `0x10*n + reg`)。
- エコー、ノイズ、ピッチ変調、ビブラート等は未対応。
- サンプルごとのチューニング補正はありません。サンプルは o4c が原音になるよう用意してください
  (`mksample.py` は 368 サンプルに 3 周期を入れて 260.9Hz = 約 -4 cent にしています)。
- 離鍵と発音は tick 単位でまとめて DSP に書きます。

## 動作確認

`libgme` で `example/demo.mml` を再生し、FFT で測定した結果:
音高は期待値と ±10 cent 以内 (サンプルの調律誤差分)、0.25 秒刻みの発音・休符、
`L` によるループ、パン (B ch が左寄り)、`q` による離鍵、`t` の切り替えが想定どおり動作しました。

## イベント形式

| バイト列 | 意味 |
|---|---|
| `pitch len` (`$00-$7F`) | ノート |
| `$80` | トラック終端 |
| `$81 lo hi` | ジャンプ |
| `$82 n` | テンポ (タイマー0 分周値) |
| `$83 n` / `$84 n` / `$85 n` / `$86 n` | 音色 / 音量 / パン / ゲート |
| `$C8 len` / `$C9 len` | タイ / 休符 |
