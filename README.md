# mmlc — 汎用 SFC(SNES) SPC 用 MML コンパイラ

MML から `.spc` を生成する C 製コンパイラです。ドライバ固有の知識はすべて
**ドライバ定義ファイル(.drv)** に外出ししているため、コンパイラ本体は変更せずに
様々な SPC ドライバに対応できます。

```
cc -O2 -Wall -o mmlc mmlc.c
./mmlc [-d driver.drv] [-o out.spc] [-v] song.mml
```

## 1. MML 仕様 (意図的に最小)

| 記述 | 意味 |
|---|---|
| `A`〜`H` で始まる行 | チャンネル指定。`AB` のように複数並べると同じ内容を複数chへ。無印行は直前の続き |
| `c d e f g a b` + `+ # -` | 音符 (`+`/`#` シャープ, `-` フラット) |
| 音長 `4` `8.` `%24` | 分音符 / 付点 / tick 直指定 (`c%24`)。省略時は `l` の値 |
| `r` | 休符 |
| `^` | タイ(直前の音符/休符の延長)。`c4^8` |
| `l8` | デフォルト音長 |
| `o4` `<` `>` | オクターブ設定 / 下げる / 上げる |
| `[ ... ]n` | n 回ループ (n 省略時 2)。ネスト可 |
| `L` | ループポイント(そこからトラック末尾でジャンプ) |
| `t` `@` `v` `p` `q` `u` | テンポ / 音色 / 音量 / パン / ゲート / ベロシティ。**数値はドライバの値をそのまま渡す** |
| `;` `//` | コメント |
| `#title #game #artist #comment #dumper #length #fade` | SPC タグ |
| `#driver "x.drv"` | 使用ドライバ(`-d` が優先) |
| `#sample "file" addr` | バイナリ(BRR サンプル等)を RAM の `addr` に直接配置。複数可。パスは MML 相対 |
| `#dsp reg val` | DSP レジスタ初期値を設定(サンプルディレクトリ `0x5D` 等)。複数可 |
| `#bin "file"` | 曲データ末尾などに埋め込む任意バイナリ(音色テーブル等)。レイアウトの `bins` で出力 |

拡張命令(ビブラート、エンベロープ等)は意図的に持ちません。ドライバ固有の機能は
ドライバ定義側の `data` や `#bin` で補います。

## 2. ドライバ定義ファイル(.drv)

INI 風のテキスト。`;` 以降はコメント。パスは .drv の位置からの相対。

### 2.1 式とトークン

テンプレートは空白区切りのトークン列で、各トークンは式です。出力サイズは末尾の
サフィックスで指定します。

| サフィックス | 意味 |
|---|---|
| (なし) / `:b` | 1 バイト |
| `:w` / `:W` | 16bit リトルエンディアン / ビッグエンディアン |
| `:l` / `:L` | 24bit LE / BE |

式は `+ - * / % << >> & | ^ ~ ( )`、10進 / `0x` / `0b` 数値、変数 `$name`、ラベル `@name` が使えます。
トークン内に空白は書けません。範囲外の値はエラーになります。

テンプレートで使える変数:

| 変数 | 内容 |
|---|---|
| `$1` | MML コマンドの引数 / ループ回数 |
| `$len` `$lenidx` | 音長(tick) / `len_table` の添字 |
| `$pitch` | 音程。絶対モード: `(o - octave_base)*12 + 半音`、オクターブ命令モード: 半音(0-11) |
| `$semi` `$oct` | 半音(0-11) / オクターブ(`octave_base` 補正後) |
| `$gate` `$vel` | `q` / `u` の現在値 |
| `$count` | ループ回数(`loop_end` 内) |

ラベル: `@here`(テンプレート先頭のアドレス) `@next`(直後のアドレス) `@loop` `@loop_body`(ネイティブループ)
`@loop_point` `@base` `@end` `@size` `@track_N` `@track_N_loop` `@track_N_end` `@used_N` `@used_mask` `@bin_N`、
および `label` で定義したもの。

### 2.2 `[spc]` — 初期 SPC イメージ

| キー | 内容 |
|---|---|
| `load = file addr` | バイナリを RAM に配置(ドライバ本体・サンプル等。複数可) |
| `dsp_file` / `dsp = reg val` | DSP レジスタ初期値(複数可) |
| `poke = addr val` | RAM の任意バイトを書き込み(タイマー設定等) |
| `pc a x y psw sp` | 開始レジスタ(`pc` は必須) |

### 2.3 `[song]` — 配置

| キー | 内容 |
|---|---|
| `base` | 曲データを置く RAM アドレス (既定 0x2000) |
| `limit` | 曲データが超えてはいけない最終アドレス (既定 0xFFBF) |
| `channels` | トラック数 (最大 16、既定 8) |
| `unused_ptr` | 未使用トラックのポインタ値 (`@track_N`) |
| `patch = addr tokens...` | 曲配置後に RAM へ書き込む(曲ポインタをドライバ変数へ設定する等、複数可) |

### 2.4 `[notes]` — 音符の意味付け

| キー | 内容 |
|---|---|
| `tpq` | 4 分音符あたりの tick (既定 48) |
| `octave_base` | `$pitch=0` に対応する MML オクターブ |
| `octave_default` / `octave_init` | MML 側の初期オクターブ / ドライバ側の初期オクターブ(up/down 方式で使用) |
| `len_table` | 音長テーブル(tick 値を並べる)。ない音長は大きい順に分割してタイで繋ぐ |
| `len_max` `len_min` | `len_table` が無い場合の 1 イベントの音長範囲 |
| `pitch_min` `pitch_max` | 絶対ピッチの範囲チェック |
| `loop_mode` | `expand`(既定: ループを展開) / `native`(ドライバのループ命令を使う) |
| `default_gate` `default_velocity` | `$gate` `$vel` の初期値 |

### 2.5 `[commands]` — バイト列テンプレート

定義がないコマンドは「非対応」として警告付きで無視されます(`gate` `velocity` は未定義なら `state` の変数になります)。

| キー | 出力されるタイミング |
|---|---|
| `note` `rest` `tie` | 音符 / 休符 / 分割された後続部分 |
| `state` | 音符・休符・タイの前。`$len $gate $vel` のいずれかが前回出力から変わった時だけ出力 (N-SPC 型) |
| `octave` | 絶対オクターブ設定 (`$1`)。あればオクターブ命令モード |
| `octave_up` `octave_down` | 相対オクターブ命令(差分回数だけ繰り返す) |
| `tempo` `instrument` `volume` `pan` `gate` `velocity` | `t @ v p q u` |
| `loop_begin` `loop_end` | `loop_mode=native` 時の `[` `]n`。`loop_begin` は空でも可 |
| `loop_point` `loop_forever` | `L` 位置 / `L` があるトラックの末尾 |
| `track_start` `track_end` | トラックの先頭 / 末尾 (`L` が無い場合) |

空定義(`loop_point =`)は「定義済みで出力なし」を意味し、キー自体が無い場合と区別されます。

### 2.6 `[layout]` — 曲データ全体の構造

行ごとに `item 引数` を上から順に実行します。

| item | 内容 |
|---|---|
| `label name` | 現在位置にラベル定義 |
| `data tokens...` | バイト出力。**前方参照可**(最後にまとめて解決) |
| `track N` / `tracks` | トラック N / 使用中の全トラックの本体を出力 |
| `foreach_track <item>` | 各チャンネルで `$ch` を数値に置換して繰り返し(例: `foreach_track data @track_$ch:w`) |
| `incbin file` | .drv 相対のファイルをそのまま出力 |
| `bins` | MML の `#bin` を全て出力 (`@bin_N` ラベル付き) |
| `align n` | n アドレス境界まで 0 埋め |

## 3. 表現できる代表的な構造

| ドライバの特徴 | 定義方法 |
|---|---|
| 音長が音符の前(変化時のみ)に付く (N-SPC 型) | `state = $len ...` |
| 音程+音長が 1 バイト結合 | `len_table` + `note = $pitch*8+$lenidx` |
| 音長が音符の後ろに付く | `note = 0x80+$pitch $len` |
| オクターブ命令 / 相対オクターブ | `octave` / `octave_up` `octave_down` |
| ネイティブループ(絶対/相対アドレス) | `loop_mode=native` + `@loop_body` `@next` |
| ループがサブルーチン方式 | `loop_mode=expand` (展開) |
| トラックポインタ表、チャンネルマスク、区間リスト | `[layout]` の `data` / `foreach_track` |
| 曲ポインタをドライバ変数に設定 | `patch = addr @label:w` |
| 音色テーブル等の曲ごとバイナリ | `#bin` + `bins` / `incbin` |
| テンポ等の単位変換 | 式 (`tempo = 0xE7 ($1*256+312)/625`) |

## 4. 制限と注意

- 同梱の `nspc_like.drv` `combined_like.drv` は**書き方の例**です。実在ドライバの命令番号・
  ヘッダ構造は、そのドライバの仕様に合わせて検証してください。
- ネイティブループ内でオクターブが相殺されない MML は、2周目以降で意図とずれることがあります
  (`octave` 絶対命令がある場合はループ先頭で状態を再出力します)。
- 音色・BRR サンプルはコンパイラでは生成しません。MML の `#sample` / `#dsp` で読み込みます(ドライバ本体は .drv の `load`)。
- ベース .spc を流用する仕組み(`base_spc`)は廃止しました。
- 1 トラック内の複数 `L`、ループ脱出 (`/`)、ポルタメント等はサポートしません。
